# 📚 Book / Novel Summarizer

A simple web app that generates concise summaries from pasted book or novel text — no sign-up, no installs, just paste and go.

---

## 🔍 What It Does

Paste any block of book or novel text into the input field, hit **Summarize**, and get a clean, concise summary back in seconds.

---

## 🛠️ Built With

- HTML5
- CSS3

---

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Lerato-1/book-summarizer.git
   ```
2. Open `index.html` in your browser — no server or dependencies needed.

---

## 💡 How to Use

1. Paste your book or novel text into the text area
2. Click the **Summarize** button
3. Wait for the summary to generate
4. Read your condensed summary in the output box
